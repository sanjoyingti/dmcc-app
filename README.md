# 26-DMCC

**26-DUARBAGORI MANDAL CONGRESS COMMITTEE** — Android app (Kotlin / Jetpack Compose + Firebase).

- Register with mobile number (OTP) or email
- Groups visible only to their members; creator is Administrator and can appoint sub-administrators
- Admins add members from contacts or by number/email; non-users get an invite link
- Primary Congress Committees (PCC) per village, with designations (President, Secretary, …)
- Voter ID, Aadhaar (masked) and document/photo uploads, visible only to admins and the member
- Group chat and one-to-one chat with photos/documents; voice and video calls
- Notices tab for admin announcements
- Version shown in app, with Check for updates
